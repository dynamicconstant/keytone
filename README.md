# Keytone

**Make every keystroke sound like anything you want.**

Keytone runs in the background and plays a sound each time you press a key — in any app. Pick a bundled pack, import a Mechvibes pack, drop in your own audio files, or record sounds with your mic, then map them to every key, a group of keys, or a single key.

- ⚡ **Low latency:** clips are decoded once into memory; the real-time audio callback never locks or allocates. Typical key-to-sound time is under 10 ms.
- 🎹 **Per-key mapping:** pack default → key group (letters, modifiers, space, …) → individual key, separately for press and release.
- 🎲 **Sounds natural:** random variant per press (never the same twice in a row) plus subtle pitch and loudness variation.
- 🎙 **Bring your own sounds:** import WAV/MP3/OGG/FLAC/M4A, or record from the mic (auto-trimmed and normalized).
- 📦 **Packs:** export/import as `.keytone` files, and import **Mechvibes** packs directly.
- 🔒 **Private by design:** Keytone only knows *which physical key* moved, never what you typed. Nothing is logged, stored or sent. No network access.

## Download

Grab the latest installer from **[Releases](https://github.com/dynamicconstant/keytone/releases/latest)**:

| OS | File |
|---|---|
| macOS (Apple Silicon & Intel) | `Keytone_x.y.z_universal.dmg` |
| Windows | `Keytone_x.y.z_x64-setup.exe` |
| Linux | `.AppImage` or `.deb` |

**First launch on macOS:** builds aren't notarized by Apple yet, so macOS says *"Keytone" Not Opened*. Click **Done** (not Move to Trash), then either:

- open **System Settings → Privacy & Security**, scroll to *"Keytone" was blocked…* and click **Open Anyway**, or
- run `xattr -dr com.apple.quarantine /Applications/Keytone.app` in Terminal.

Then allow **Input Monitoring** for Keytone when asked; it lets Keytone hear key presses in other apps.

**First launch on Windows:** SmartScreen may say "unknown publisher": click **More info → Run anyway**.

## Building from source

Prerequisites: [Rust](https://rustup.rs) (stable), Node.js 20+, and the [Tauri prerequisites](https://tauri.app/start/prerequisites/) for your OS.

```bash
npm install
npm run tauri dev        # run in development
npm run tauri build      # build an installer for your OS
```

Try the key listener on its own: `cargo run -p keyhook --example listen`.

Run tests: `cargo test -p keyhook -p keytone-core`.

### Platform notes

| | |
|---|---|
| **macOS** | On first launch Keytone asks for **Input Monitoring** permission (System Settings → Privacy & Security). Distribute signed + notarized builds, or Gatekeeper will block the app. |
| **Windows** | Works out of the box. Unsigned builds trigger a SmartScreen warning; sign them for release. Some anti-cheat software blocks keyboard hooks while games run. |
| **Linux** | Works on **X11** sessions. Wayland doesn't allow apps to observe global key presses, so Keytone shows a notice there. |

## How it works

```
keyhook (OS hook thread) ──KeyEvent──▶ dispatch thread ──▶ Mapper ──PlayCmd──▶ Engine (cpal)
     macOS: CGEventTap                    │                (repeat-suppression,      lock-free queue,
     Windows: WH_KEYBOARD_LL              │                 variant pick,            48-voice mixer,
     Linux: XRecord                       │                 pitch/gain jitter)       soft limiter
                                          └──▶ UI (live key highlight, only while the window is visible)
```

| Path | What's there |
|---|---|
| `crates/keyhook` | Tiny global key listener per OS. Emits W3C key codes only. Never calls `ToUnicode`/TIS APIs, so it doesn't break dead keys (é, ñ) or crash on macOS 14+. |
| `crates/keytone-core` | Pack format & loader (`pack.rs`), mapper, audio engine, mic recorder, pack library, Mechvibes importer. All unit-tested. |
| `src-tauri` | Tauri app: commands, settings, tray menu, global on/off shortcut, launch at login. |
| `src` | React UI: on-screen keyboard editor, pack library, settings, recorder, macOS permission walkthrough. |
| `packs` | Bundled starter packs (procedurally generated by `tools/make_packs.py`, free to redistribute). |
| `docs/PACK_FORMAT.md` | The `pack.json` spec. |

## Releasing

Bump the version in `src-tauri/tauri.conf.json` and `package.json`, commit, then publish:

```bash
git push origin main:release
```

(or open **Actions → release → Run workflow**). GitHub Actions builds the macOS, Windows and Linux installers and publishes them as release `v<version>`.
